# Accessible Form UI

An accessible profile-update form built with HTML and CSS only — no JavaScript. The form is a static UI for now and can be made functional with JavaScript later.

## Features
- Full Name, Email, Enter Password, and Confirm Password fields
- Show/hide password buttons
- Profile Completeness progress circle at 65% with a checklist
- Accessible labels, focus states, error messaging, and ARIA attributes

## Files
- `index.html` — Accessible form UI page
- `styles.css` — Layout, form styling, and responsive styles

## How to run it
Double-click `index.html` to open it in your browser, or view the live site below.
